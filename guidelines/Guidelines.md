# Agent Guidelines

Project rules and coding constraints live in `CLAUDE.md`. Full design rationale, architecture decisions, and delivery plan are in `project.md`. The domain glossary is `CONTEXT.md`.

When modifying this codebase:

- Read `CLAUDE.md` for hard constraints (design system, interaction rules, data rules, security, PWA contract, tech stack).
- Read `CONTEXT.md` for the ubiquitous language before naming anything new.
- Read `docs/adr/` for architectural decisions that affect the area you're touching.
- Read `project.md` for the full picture before major feature work or design changes.
